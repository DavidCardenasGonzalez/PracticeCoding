# Algorithm Practice Track

This track contains short TypeScript exercises for recognizing common algorithmic
patterns. Solve one topic at a time and use its focused Vitest command for fast feedback.

## Practice method

1. Read only the problem statement and examples.
2. Write down the expected time and space complexity before coding.
3. Implement the function without changing its public contract or tests.
4. Run the focused test suite.
5. After it passes, explain why the chosen pattern applies and name its edge cases.

The starter functions intentionally throw `Not implemented`. A failing focused suite is
the initial state of an unsolved topic.
